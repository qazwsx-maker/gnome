1 · ความเป็นไปได้

ทำได้แน่นอน ทุก node เป็นของที่ชุมชน ESP32 ทำกันเป็นมาตรฐาน ความเสี่ยงจริงไม่ได้อยู่ที่ซอฟต์แวร์ แต่อยู่ที่ ฮาร์ดแวร์ในสวนที่มีพ่นหมอก และ ความปลอดภัยของระบบรดน้ำเมื่อ WiFi หลุด

หัวข้อความยากหมายเหตุ
Sensor node (อุณหภูมิ/ความชื้น/แสง)ง่ายใช้ ESPHome ได้เลย ไม่ต้องเขียน firmware
Ground sensor (ความชื้นดินหลายจุด)กลางตัวเซ็นเซอร์คือจุดอ่อน ต้อง calibrate ทีละกระถาง
Water controller (solenoid 2 ชุด)กลางต้องมี fail-safe ในตัว node (max-on timer) ห้ามพึ่ง server อย่างเดียว
Airflow (พัดลม 220 V)ง่ายESP32 + relay คุมเต้ารับในกล่องปิด แยกฝั่ง 220 V ชัดเจน วงจรต้องมี RCD
Camera + AIกลาง-ยากESP32-CAM ภาพแย่ตอนกลางคืน; YOLO บน M4 ไหว; "หนู" ไม่มีใน COCO ต้องใช้ motion + VLM
Server: status/logs/webapp/automation/Discordกลางสแต็คที่มีอยู่แล้วบน Mac mini รองรับหมด
Public access + loginง่ายCloudflare Tunnel + Access (มี cloudflared อยู่แล้ว) ไม่ต้อง forward port

2 · สถาปัตยกรรม

MQTT topic contract

gnome/<node>/status                    retained online|offline (LWT)
gnome/<node>/sensor/<name>/state       ค่า sensor ทุก 30 s (ดิน 60 s)
gnome/<node>/switch/<name>/command     ON|OFF   ← server สั่ง
gnome/<node>/switch/<name>/state       ON|OFF   → node ยืนยัน
gnome/<node>/debug                     rssi · uptime · heap · ip

ตัวอย่าง rule (JSON ใน Postgres)

{ "name": "รดน้ำเช้า",
  "trigger": { "type":"cron", "expr":"0 6 * * *", "tz":"Asia/Bangkok" },
  "conditions": [ { "sensor":"ground.soil_median", "op":"<", "value":45 } ],
  "actions": [
    { "switch":"water.drip", "state":"ON",
      "until": { "sensor":"ground.soil_median", "op":">=", "value":60 },
      "max_minutes": 8 },
    { "discord": "รดน้ำเสร็จ {duration} นาที ดิน {soil}%" } ] }

"until + max_minutes" = feedback stop point จากความชื้นดินพร้อมเพดานเวลา · interlock: drip↔mist ห้ามเปิดพร้อมกัน, mist ห้ามเปิดถ้า RH > 85 %

3 · Nodes และการทำให้ทน (ruggedization)

    6 · รายการอุปกรณ์และงบประมาณ

    ติ๊ก ☑ เมื่อซื้อแล้ว — บันทึกไว้ในเบราว์เซอร์นี้ · ตัวหนา = ราคาจริงบนเว็บร้าน (เช็ค 26 ก.ย. 2026) · ≈ = ประเมิน

    งบต่อ node · เทียบสองระดับ

    บาท · ไม่รวมพัดลม กล้อง IP สำรอง และค่าติดตั้งท่อ

    งบประหยัดระดับทน

    จ่ายเพิ่มตรงไหนคุ้ม

    1. RS485 soil sensor แทน capacitive แผ่นทองแดง — ชิ้นที่พังในสวนบ่อยสุด
    2. SHT31 แบบ probe กันน้ำ / PTFE cap — ไม่ใช้ DHT22 ที่ตายเร็วในความชื้นสูง
    3. UPS ให้ Mac mini + router — server คือสมองของทั้งสวน
    4. วาล์วทองเหลือง — ทนแรงดัน/ทนแดดกว่าพลาสติก

    ไม่ต้องจ่ายเพิ่ม: บอร์ด ESP32 (ของถูกใช้ได้ดี ซื้อสำรองแทน), relay module

    7 · ความเสี่ยงหลักและวิธีรับมือ

    โจทย์จากเจ้าของสวน (ตอบ 2026-09-26) และผลต่อแพลน

    1. น้ำต่อจากก๊อกตรง ไม่ต้องมีปั๊ม → ตัดปั๊มหมอกออก · ใช้หัวหมอกไมโครแรงดันก๊อก · ต้องมี filter + regulator หน้าวาล์ว
    2. กระถาง 10 ใบ บนซุ้มโค้งยกพื้น + สแลนพรางแดด → น้ำหยด 10 หัว, หมอก 6–8 หัวตามแนวซุ้ม, soil probe สุ่ม 3–5 ใบ · เดินสาย/ท่อตามโครงซุ้ม กล่องทุกใบยกสูงพ้นแนวหมอก · สแลนช่วยลดอุณหภูมิและทำให้ BH1750 อ่านค่าแสงหลังพราง
    3. มีปลั๊ก 220 V ใกล้สวนแล้ว → ตัดปลั๊กพ่วง outdoor ออก · ต้องเช็คว่าวงจรนั้นมีเบรกเกอร์กันดูด (RCD) ถ้าไม่มีให้ติดปลั๊กกันดูดแบบเสียบ (≈ 400–600 ฿) ก่อนต่ออะไรทั้งสิ้น
    4. router ใกล้มาก → ตัด mesh node ออก
    5. พัดลมบ้าน 220 V ใช้ relay คุมเต้ารับ → airflow node = ESP32-C3 + relay 10 A + เต้ารับติดกล่อง ในกล่องกันน้ำ แยกโซน 220 V/5 V, relay ตัดสาย L, มีฟิวส์ · พัดลมบ้านมอเตอร์ ~50–70 W กระแสสตาร์ทต่ำ relay 10 A พอ
