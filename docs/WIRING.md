# ต่อสาย Scout — earth กับ sky

ผังขาตรงกับแคตตาล็อกใน firmware 0.6.0 (`firmware/src/sensors.cpp`) ติ๊กเลือกเซ็นเซอร์ได้ที่หน้า
`http://<ip>/` ของแต่ละ node โดยไม่ต้องกรอกเลขขาเอง

## กฎที่ใช้กับทั้งสองตัว

- **ไฟเลี้ยงเซ็นเซอร์เป็น 3.3V เสมอ ห้าม 5V** โมดูล analog ที่เลี้ยงด้วย 5V จะส่งแรงดันเกิน 3.3V
  เข้าขา ADC แล้วพัง
- **ขา analog ต้องเป็น ADC1 เท่านั้น** (D32 D33 D34 D35 VP VN) ขาอื่นเป็น ADC2 ซึ่งอ่านไม่ได้เลย
  ขณะเปิด WiFi — firmware จะปฏิเสธถ้าตั้งผิดขา
- **ขา DO ของโมดูล analog ไม่ต้องต่อ** เราใช้ค่าต่อเนื่องจาก AO ไม่ใช่สัญญาณเปิด/ปิด
- **VCC ของโมดูล analog ต่อเข้า D13 ไม่ใช่ 3V3** firmware จ่ายไฟเฉพาะ 150 มิลลิวินาทีตอนอ่าน
  แล้วตัด หัววัดแบบ resistive กร่อนจากไฟที่ค้างอยู่ตลอดเวลา ไม่ใช่จากน้ำ
- ขั้วสกรูมีรูเดียวต่อขา ขาที่ต้องแยกไปหลายตัว (3V3, GND, D13, D21, D22) ให้พักผ่าน
  **ขั้วต่อสายไฟ** ที่ซื้อไว้ (6 ช่อง 1 ตัว, 2 ช่อง 5 ตัว) อย่าพันสายยัดรูเดียวถ้าเลี่ยงได้

## earth — อากาศ + ดิน

ของเดิม: AM2301A และจอ OLED · ของใหม่: หัววัดดิน 2 ตัว

| อุปกรณ์ | สาย | เข้าขั้ว |
|---|---|---|
| AM2301A | แดง (VCC) | 3V3 |
| | เหลือง (DATA) | **D4** |
| | ดำ (GND) | GND |
| จอ OLED | VCC | 3V3 |
| | GND | GND |
| | SCL | **D22** |
| | SDA | **D21** |
| หัววัดดิน #1 | AO | **D34** |
| | VCC | **D13** |
| | GND | GND |
| หัววัดดิน #2 | AO | **D35** |
| | VCC | **D13** |
| | GND | GND |

**ยังค้างอยู่:** ใส่ตัวต้านทาน **4.7–10 kΩ คร่อมระหว่าง D4 กับ 3V3** นี่คือสาเหตุที่ค่าจาก
AM2301A หลุดเป็นช่วงๆ มาตลอด สายยาวแบบนี้ต้องมี

ปักหัววัดในกระถางคนละใบ ให้ลึกพอที่แผ่นโลหะจมดินทั้งแผ่น อย่าให้โดนก้นกระถาง

## sky — แสง + ฝน

ของเดิม: โดม BH1750 · ของใหม่: ฐานรอง terminal, แผ่นวัดน้ำฝน, จอ OLED

| อุปกรณ์ | สาย | เข้าขั้ว |
|---|---|---|
| โดม BH1750 | 1 VCC | 3V3 |
| | 2 SCL | **D22** |
| | 3 DAT | **D21** |
| | 4 GND | GND |
| | 5 ADDR | ปล่อยลอย |
| จอ OLED | VCC | 3V3 |
| | GND | GND |
| | SCL | **D22** |
| | SDA | **D21** |
| แผ่นวัดน้ำฝน | AO | **D33** |
| | VCC | **D13** |
| | GND | GND |

โดมกับจออยู่บนสาย I2C เส้นเดียวกันได้ เพราะคนละแอดเดรส (โดม 0x23 · จอ 0x3C) ต้องพัก D21
กับ D22 ผ่านขั้วต่อสายไฟเพื่อแยกไปสองทาง

**ติดแผ่นรับน้ำให้เอียงอย่างน้อย 30°** ถ้าวางราบน้ำจะขังบนแผ่นแล้วค่าค้างว่าฝนตกทั้งที่หยุดไปแล้ว

## หลังต่อเสร็จ

1. เสียบไฟ รอ node ขึ้นออนไลน์บน Hut
2. เปิด `http://<ip>/` ของ node แล้วติ๊กเซ็นเซอร์ที่ต่อจริง
   - earth: AM2301A, หัววัดดิน #1, หัววัดดิน #2
   - sky: แผ่นวัดน้ำฝน
   - จอกับโดมไม่ต้องติ๊ก ระบบสแกน I2C เจอเอง
3. กดบันทึก node จะรีบูตแล้วเริ่มส่งค่า
4. **ปรับเทียบหัววัด** ค่าเริ่มต้นเป็นของหัว capacitive คนละสเกลกับหัว resistive ที่เรามี
   ถ้าไม่ปรับ เปอร์เซ็นต์จะเพี้ยน วิธีคืออ่านค่า raw ตอนหัวแห้งในอากาศ แล้วอ่านอีกครั้ง
   ตอนปักในกระถางที่เพิ่งรดน้ำ เอาสองค่านั้นไปใส่ช่อง dry/wet ในหัวข้อ "ขั้นสูง"

## เช็กว่าต่อติดไหม

- จอติด = I2C ใช้ได้
- บน Hut เห็นค่า `lux` (sky) และ `dht_temp_c`/`dht_rh_pct` (earth) = เซ็นเซอร์นั้นมาแล้ว
- เห็น `soil1_pct`, `soil2_pct`, `rain_pct` = ช่อง analog มาแล้ว
- เจอตัวเดียวจากสองตัวบนบัส I2C มักเป็นสายไม่แน่น ไม่ใช่โมดูลเสีย
