## 4. สิ่งที่ราคาจริงเปลี่ยนจากประเมิน

- **SHT31 → SHT30 หัวกันน้ำ 150 ฿** ถูกกว่าประเมิน (350) มาก · รุ่น ArtronShop 469 ฿ ทนกว่า มีขายึด
- **BH1750 → โดมตะวัน 280 ฿** เป็นตัวกันน้ำจริงพร้อมสาย ตัดงานทำช่องใสเอง · แนะนำใช้ตัวนี้ในระดับทน
- **RS485 soil 1,300–1,400 ฿/หัว** แพงกว่าประเมิน (500) เกือบ 3 เท่า → ระดับทนใช้ 2 หัว (ริม/กลาง) + capacitive 2 หัวเสริม แทน 3 หัว RS485
- **Solenoid ทองเหลือง 482 ฿** แพงกว่าประเมิน (350) · พลาสติก 110 ฿ ถูกกว่าประเมิน (180)
- **กล่อง IP65 140 ฿** ถูกกว่าประเมิน · **XIAO S3 Sense 990 ฿** แพงกว่าประเมิน (900) เล็กน้อย
- **UPS 800 VA ≈ 2,000–2,400 ฿** สูงกว่าประเมิน (1,800)
