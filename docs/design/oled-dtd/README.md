# OLED UI แนว Dave the Diver — mockup

`mockup.png` คือภาพที่เรนเดอร์ผ่าน U8g2 ตัวเดียวกับที่บอร์ดใช้ บนบัฟเฟอร์ SH1106 128×64 จริง
ขยาย 4 เท่า — สิ่งที่เห็นคือสิ่งที่จอจะแสดงเป๊ะทุกพิกเซล

ภาษาภาพที่ยืมมาจากเกม (แปลงเป็นขาวดำ 1 บิต)
- **ขอบหนาสองชั้น + มุมมน** ทุกแผง/บอลลูน (panel)
- **แถบพลังงานเป็นช่อง** แบบ O2 bar → ใช้กับความชื้นดิน/ความชื้นอากาศ
- **ตัวเลขฟอนต์อาร์เคด** `pressstart2p` แบบเครื่องวัดความลึก → อุณหภูมิ
- **ช่องไอเท็ม** แถวล่าง → สถานะเซ็นเซอร์ (ติ๊กแล้วสว่าง)
- **บอลลูนคำพูดมีหาง** → ข้อความจากโหมดคิดของ Watcher
- **ป้ายเปิดตัวบอส** กล่องกลับสี + แถบลายทางบน-ล่าง → การแจ้งเตือน (ฝน/ร้อน/node หาย)
- **การ์ดสมุดสะสม** ไอคอนซ้าย เลขใหญ่ขวา ป้ายชื่อ node → หน้าค่าเซ็นเซอร์
- **ฟองอากาศ** ลอยขึ้นที่มุมขวา เป็นลายเซ็นใต้น้ำ (เคลื่อนไหวได้บนบอร์ด)
- **ภูตโนม 24×24** หมวกแหลมปีกกว้าง ตาโต เคราฟู ขอบหนา (XBM ใน mock.c)

ฟอนต์ที่ใช้ (มีใน U8g2 แล้ว ไม่ต้องเพิ่ม)
`u8g2_font_HelvetiPixel_tr` หัวข้อ/คำพูด · `u8g2_font_pressstart2p_8r` ตัวเลข HUD/ป้ายเตือน ·
`u8g2_font_4x6_tr` ข้อความรอง · `u8g2_font_logisoso24_tn` เลขใหญ่บนการ์ด
