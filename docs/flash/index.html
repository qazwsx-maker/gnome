🌿 GnomeOS — flash firmware

ติดตั้ง firmware ลง ESP32 จากเบราว์เซอร์ผ่านสาย USB ไม่ต้องลงโปรแกรมอะไร · ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (Safari/iPhone ใช้ไม่ได้) · บอร์ดเป้าหมาย: ESP32 DevKit (ESP32-WROOM-32)

Scout — ESP32-S3 UNO sensor node

Scout ตัวหลัก: จอ OLED (ข้อมูล + หน้าอารมณ์) · BH1750 โดม · DHT22 · raindrop · ดิน — I2C ที่ IO8 (SDA) / IO9 (SCL), analog A0–A5 = IO2 IO1 IO7 IO6 IO5 IO4, RGB LED ในตัว

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Chrome/Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS

Scout — Waveshare ESP32-C6-LCD-1.47 sensor node

บอร์ด C6 จอสี (จอยังไม่ใช้ในเวอร์ชันนี้) · I2C ที่ GPIO19 (SDA) / 18 (SCL) · analog GPIO0–6 · ไฟ RGB ในตัว · USB ในตัวไม่ต้องไดรเวอร์

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Chrome/Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS

Mini Scout — ESP32 DevKit 30 ขา sensor node

จอ OLED + DHT22 + ดิน (หรือ SHT3x/BH1750/BME280 ทาง I2C 21/22) · หัววัด analog ที่ 32 33 34 35 36 39

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Chrome/Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS

Keeper — บอร์ด ESP32-Relay-X4 controller node

สำหรับบอร์ด LC Technology ESP32-Relay-X4 (relay 10A ×4 ในตัว รับ 220VAC) ค่าเริ่มต้น: pump=relay1 (GPIO32, ปั๊ม 12V น้ำหยด) · fan=relay2 (33, เต้ารับพัดลม 220V) · mist=relay3 (25) · aux=relay4 (26) active-high · LED GPIO23 · จอ OLED ที่ 21/22 · บอร์ดนี้ไม่มี USB ต้องต่อผ่าน USB-TTL (ดูด้านล่าง)

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Chrome/Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS

Keeper — ESP32 DevKit + relay module controller node

ESP32 DevKit ต่อ relay module แยก (drip GPIO26, mist GPIO27 active-low) สูงสุด 4 ตัว พร้อม max-on timer, interlock และ failsafe

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Chrome/Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS
flash ครั้งเดียวพอ: หลังตั้ง WiFi + MQTT แล้ว การอัปเดต firmware ครั้งต่อไปทำจาก dashboard บน Mac mini (ปุ่ม "อัปเดต OTA") node จะดาวน์โหลดจาก server เองแล้วรีบูต ค่าที่ตั้งไว้ไม่หาย

ขั้นตอน

  1. เสียบ ESP32 เข้า USB ของคอม (ถ้าเป็นบอร์ดชิป CH340/CP2102 บน Mac รุ่นใหม่มักใช้ได้เลย ถ้าไม่ขึ้นพอร์ต ให้ลงไดรเวอร์ CH34x/CP210x)
  2. กดปุ่ม ติดตั้ง ของ role ที่ต้องการ → เลือกพอร์ต (ชื่อประมาณ cu.usbserial-xxxx หรือ cu.SLAB_USBtoUART) → เลือก Install · ครั้งแรกให้ติ๊ก "Erase device" ด้วย
  3. บอร์ดบางรุ่นต้องกดปุ่ม BOOT ค้างตอนเริ่มเชื่อมต่อ ถ้าขึ้น "Failed to initialize" ให้ลองใหม่โดยกด BOOT ค้างไว้
  4. เมื่อ flash เสร็จ หน้าจะเสนอให้ ตั้งค่า Wi-Fi ทันที (Improv) — เลือก WiFi บ้าน 2.4G ใส่รหัส แล้วจะได้ลิงก์ไปหน้าเว็บของ node
  5. ในหน้าเว็บของ node ใส่ ชื่อ node (เช่น air, ground, water) และ MQTT host = IP ของ Mac mini, user gnome + password (อยู่ใน infra/.env บน Mac mini) แล้วกดบันทึก

ถ้าไม่ได้ตั้ง WiFi ตอน flash (หรือย้ายบ้าน)

node จะเปิด WiFi ของตัวเองชื่อ GNOME-Scout-xxxx / GNOME-Keeper-xxxx รหัส gnome1234 — ต่อจากมือถือแล้วหน้าตั้งค่าจะเด้งขึ้นเอง (หรือเปิด http://192.168.4.1/) ตั้ง WiFi + MQTT ได้จากตรงนั้น · หลังต่อ WiFi บ้านได้แล้วเปิด http://<ชื่อ node>.local/ เพื่อแก้ค่าภายหลัง

ไฟ LED บนบอร์ด: กระพริบเร็ว = โหมดตั้งค่า · กระพริบช้า = ต่อ WiFi ได้แต่ยังไม่ถึง MQTT · กระพริบสั้นทุก 5 วินาที = ทำงานปกติ

บอร์ด ESP32-Relay-X4 (ไม่มี USB) — flash ผ่าน USB-TTL

  1. ใช้ USB-to-TTL adapter 3.3V (CP2102 / FTDI / CH340 ที่ตั้ง 3.3V ได้) — บัดกรี pin header ที่แถมมาลงบอร์ดก่อน
  2. จ่ายไฟบอร์ดที่ขั้ว 5V (จากขา 5V ของ adapter) หรืออะแดปเตอร์ 12V เข้าขั้ว 7–30V · ห้ามใช้ 3.3V จาก adapter จ่ายบอร์ด (brownout) · ยังไม่ต้องต่อ 220V ตอนโปรแกรม
  3. ต่อ 3 เส้น: adapter GND ↔ บอร์ด GND · adapter TX → บอร์ด RX · adapter RX → บอร์ด TX
  4. เข้าโหมดโปรแกรม: กด IO0 ค้าง → กด EN แล้วปล่อย → ปล่อย IO0
  5. กด "ติดตั้ง GnomeOS Keeper (Relay-X4)" เลือกพอร์ตของ adapter → Install → เสร็จแล้วกด EN · ตั้ง WiFi ผ่าน Improv ได้เหมือนบอร์ดอื่น หลังจากนั้นอัปเดตทาง OTA ที่ http://<node>.local/ ไม่ต้องต่อสายอีก

ทางลัด: บอร์ด ESP32-CAM-MB ใช้เป็น adapter ได้ — ช่อง U0R = TX ของ adapter, U0T = RX, พร้อม GND/5V และปุ่ม IO0 ของ MB ต่อไปขา IO0 ของบอร์ด relay

ทางเลือกอื่น

OTA จากหน้าเว็บของ node: เปิด http://<node>.local/ → อัปโหลด firmware.bin (ดาวน์โหลด: scout-s3 · scout · keeper-relayx4 · keeper)

PlatformIO: cd firmware && pio run -e scout -t upload (โฟลเดอร์ firmware/ ใน repo)

esptool:

esptool.py --chip esp32 --baud 460800 write_flash -z \
  0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
# ESP32-S3: bootloader อยู่ที่ 0x0
esptool.py --chip esp32s3 write_flash -z 0x0 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
